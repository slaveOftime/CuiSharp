# Trace viewer

Generated by `tools/bindgen.cs` from the CUI headers. Do not edit.

Call these inside a frame, on a `Ui` value:

```csharp
protected override void Draw(Ui ui)
{
    using (ui.TraceView(/* options */))
    {
        // ...
    }
}
```

## `TraceSpanRect`

```csharp
public RectF TraceSpanRect(uint trace, in TraceSpan span)
```

Where a span is drawn, in points (zero size when out of view or in a folded lane below its top row): its time extent and row, as cui_flame_span_rect gives one; the bar inside is a point narrower, the gap between neighbours, and a selected sliver is widened to 3 points. trace is the view's id: cui_last_id(ui) right after the call. Asked right after the call, it answers at this frame's view in the rectangle of the previous frame, as this frame is not laid out yet; after cui_end_frame, where this frame drew it, until the next frame begins.

public TraceResult TraceView(UiText id, ReadOnlySpan<TraceTrack> tracks, ReadOnlySpan<TraceSpan> spans, ref TraceViewState view, ref int selected, TraceOpts o = default)

Draw the trace and report changes to its range, scroll position, or measurement.
