# Flame graph

Generated by `tools/bindgen.cs` from the CUI headers. Do not edit.

Call these inside a frame, on a `Ui` value:

```csharp
protected override void Draw(Ui ui)
{
    using (ui.FlameGraph(/* options */))
    {
        // ...
    }
}
```

## `FlameGraph`

```csharp
public FlameResult FlameGraph(UiText id, ReadOnlySpan<FlameSpan> spans, ref FlameView view, ref int selected, FlameOpts o = default)
```

selected: index into spans, -1 for none (may be NULL).

## `FlameSpanRect`

```csharp
public RectF FlameSpanRect(uint flame, in FlameSpan span)
```

Where a span was drawn in the latest frame, in points (zero size when out of view). flame is the graph's id: cui_last_id(ui) right after the call.
