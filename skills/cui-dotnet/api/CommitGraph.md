# Commit graph

Generated by `tools/bindgen.cs` from the CUI headers. Do not edit.

Call these inside a frame, on a `Ui` value:

```csharp
protected override void Draw(Ui ui)
{
    using (ui.CommitGraph(/* options */))
    {
        // ...
    }
}
```

## `CommitGraph`

```csharp
public CommitGraphResult CommitGraph(UiText id, ReadOnlySpan<Commit> commits, ref int selected, CommitGraphOpts o = default)
```

Version history: the branch lanes drawn beside each commit, newest first, with its message, branch and tag names, author, date and short hash. Each commit names its parents by row (parents come later in the array), so merges and branches draw as lines between lanes. Only the rows in view are built. Up and Down move the selection; Enter or a double-click activates.
