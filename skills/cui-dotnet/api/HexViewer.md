# Hex viewer

Generated by `tools/bindgen.cs` from the CUI headers. Do not edit.

Call these inside a frame, on a `Ui` value:

```csharp
protected override void Draw(Ui ui)
{
    using (ui.HexViewGoto(/* options */))
    {
        // ...
    }
}
```

## `HexViewGoto`

```csharp
public void HexViewGoto(UiText id, ulong offset)
```

Go to offset: on the view's next frame its cursor moves to offset, that byte becomes the selection and it scrolls into view (to the middle when it was out of sight). Wire a "Go to" field to it; it is safe to call every frame.
