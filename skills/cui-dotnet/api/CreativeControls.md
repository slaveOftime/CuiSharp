## `RatioSlider`

```csharp
public bool RatioSlider(UiText first, UiText second, ref float ratio, RatioSliderOpts o = default)
```

Ratio slider: a whole split into two named parts, with a bar between them to drag. *ratio is the first part's share, 0..1. Both names and percentages stay readable: the split stops where a part would get too narrow for them. Arrows move one step (Shift: ten), Home and End go to the limits.

## `SeedField`

```csharp
public int SeedField(UiText label, ref uint seed, ref bool locked, SeedFieldOpts o = default)
```

Seed field: a random seed in the monospaced font. The dice rolls a new one, its digits rolling into place, and the lock keeps it fixed (the dice is off while locked). Returns CUI_WELL_CHANGED when the seed or the lock changed and CUI_WELL_ACTION on a roll.
