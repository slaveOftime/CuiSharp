## `AvatarUpload`

```csharp
public int AvatarUpload(UiText id, UiText name, ref ulong image, float size)
```

Avatar upload: a round avatar that takes a dropped image, with a camera badge on hover. Returns 1 when *image changed, -1 when clicked (browse), 0 otherwise. A dropped image is loaded with cui_image_load.

## `Dropzone`

```csharp
public int Dropzone(UiText id, DropzoneOpts o = default)
```

Dropzone: drop files from the OS, or click to browse. Returns the number of files dropped on it this frame (read them with cui_dropped_file), -1 when clicked (open a file dialog), 0 otherwise. accept filters by extension, e.g. "png;jpg;pdf".
