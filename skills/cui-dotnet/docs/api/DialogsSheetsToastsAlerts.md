# Dialogs, sheets, toasts, alerts

Generated by `tools/bindgen.cs` from the CUI headers. Do not edit.

Call these inside a frame, on a `Ui` value:

```csharp
protected override void Draw(Ui ui)
{
    using (ui.Dialog(/* options */))
    {
        // ...
    }
}
```
